# Replenishment Flow (2 Emails)

**Flow logic and timing note:**

- This flow is the profit engine for a brand with a 50-compound catalog and a membership program, because it converts a one-time buyer into a predictable monthly reorder

- Trigger is time-since-purchase, set per product type rather than one blanket delay, since a 30 mL Recon Water and a $509.99 KLOW set do not run out on the same schedule

- Suggested trigger windows to load into the flow

- Recon Water and recon supplies: 21 days

- Single 10mg vials such as GLP-3 (R), GLP-2 (T), GLP-1 (S), BPC-157, GHK-CU: 30 days

- Larger formats and stacks such as NAD+, BPC-157 + TB-500, GLOW, KLOW: 45 days

- EvoVera topicals: 45 days

- Exclusion rules that keep this flow clean

- Suppress anyone who has already placed a new order since the trigger purchase

- Suppress active EVO+ members from the discount version and send them the member variant instead, since they already have standing pricing and credit

- Suppress anyone currently sitting in the Abandoned Checkout flow so the two offers never collide
