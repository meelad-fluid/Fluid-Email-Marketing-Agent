# Formera Research — Month 1 plan (December 2026)
_Prepared 2026-11-20 · Platform: Customer.io (proposed; client has no email software yet) · From: Erin from Formera Research (proposed)_

> **Gate on every send:** compliance status is **ESCALATE** (compliance.md §1). Each email below is a brief, not copy. Copy is written only after the classification is A, and each draft must pass the RUO gate (PASS) before design. Every product-focused email carries the approved disclaimer in the body. CTAs from compliance.md §3 only. No promotions until approved (sends 7, 8 and SMS 4–5 are marked HOLD). Do-not-feature products (compliance.md §1) appear nowhere.

**Start condition:** Customer.io live, WooCommerce events flowing, consented WooCommerce customers imported, Welcome flow on. If that slips past Dec 1, the calendar shifts week by week; the order stays.

**Audiences (segmentation master sheet, built as Customer.io data-driven segments):**
- FC | Engaged 90 / 120 / 180: opened or clicked any email, or performed `placed_order`, `checkout_started`, `added_to_cart` or a page view in the last N days, AND subscribed.
- FC | Engaged 30 ex. Purchasers (New Subs): opened/clicked/viewed a product in the last 30 days, created in the last 30 days, no `placed_order` in 30 days, subscribed.
- FC | Placed Order 7d / 14d / 30d: `placed_order` in the last N days.
- FC | Lapsed Customers (Winback): `placed_order` ever, none in 180 days, subscribed.
- Week 1 note: engagement segments are empty at launch, so the first two sends go to **Imported customers (consented)**, which feeds the master segments from then on.

**Monthly angles:** 1) The paperwork, on file (COA library, lots, dates) · 2) Read it yourself (COA education) · 3) Ships fast, answers the phone (fulfillment + support) · 4) Year-end catalog (offer, if approved).

Cadence: 3 emails a week, Tue/Thu/Sat, 10am PT. SMS only after an approved SMS disclosure (compliance.md §8).

## Emails

### 1. Tue Dec 1 · Every lot, on file
```
Email Campaign name: Every lot, on file
Sent to: Imported customers (consented) + FC | Engaged 90
Discount (if applicable): None
Angle: Talking to the small-lab buyer comparing three vendors' COAs with none listing a lot number: Formera keeps a lab report on file for every product in one library, dated, so they can check before they order.
Goals: They learn the COA library exists and how to find their product's reports in two clicks. One action: View Documentation (COA library). Designed: hero = a real COA cropped to the date/method rows next to a real vial; "that's me" section on mismatched paperwork; three-step "find your COA" visual; disclaimer in body.
Excluding: FC | Placed Order 7d; anyone who reported a problem order (support list, if available)
```
Why now: first send to a brand-new program; documentation is the one proof point that's verifiable today.

### 2. Thu Dec 3 · How to read a COA
```
Email Campaign name: How to read a COA
Sent to: Imported customers (consented) + FC | Engaged 90
Discount (if applicable): None
Angle: Talking to the buyer opening a COA for the first time and not knowing what they're looking at: a plain-language walkthrough (identity vs purity, what a test method line means, where the lot and date sit) so they can judge any vendor's paperwork, including ours.
Goals: They can read the four lines that matter on any COA. One action: View Documentation. Designed: an annotated sample COA (real Formera COA, client-approved) as the hero, four numbered callouts. General science education only; no product benefits, no product-specific pharmacology.
Excluding: FC | Placed Order 7d
```
Why now: education builds trust before any sell, and it's the SOP's safest permitted topic.

### 3. Sat Dec 5 · How fast we ship
